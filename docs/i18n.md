# Languages (Hebrew and English)

Hebrew is the source language on the website and in the app. Every text is written in Hebrew in the code and passed through a
translate function; each other language is a dictionary that maps those Hebrew texts to its own. A text a dictionary lacks shows
in Hebrew, so a missing entry never breaks a page.

What is not translated: data as the federation publishes it (names of players, clubs, competitions, categories and documents).
A few fixed data values are translated anyway because they act as labels: regulation sections, the "no club" club, group names
("בית 1" reads "Group 1") and league rounds ("מחזור 3" reads "Round 3").

## Website (`apps/web`)

- Dictionary: `src/lib/i18n.ts`, the `EN` object (`'Hebrew text': 'English text'`).
- Server components: `const t = await tr();` then `{t('טקסט')}`. The language is the `ita_lang` cookie, set by the EN / עב button.
- `<html lang dir>` and the page title follow the language.
- Finding gaps: every Hebrew string a page uses must have an `EN` entry. A quick check is to load the pages with the cookie
  `ita_lang=en` and look for Hebrew that is not data.

## App (`mobile`)

- `src/i18n/index.ts`: the list of languages (`LANGS`), `tr()`, the locale for dates, the layout direction.
- `src/i18n/en.ts`: English, keyed by the Hebrew text. Values with placeholders keep them: `'{n} שחקנים': '{n} players'`.
- In the code: `tr('טקסט')` or `tr('{n} שחקנים', { n })`. Lists defined at module level keep Hebrew and are translated where
  they are displayed (`tr(label)`), so a language change applies at once.
- The choice is saved on the phone; the whole app re-renders in the new language and direction.

## Adding a language to the app

1. Copy `mobile/src/i18n/en.ts` to `<code>.ts` (for example `ru.ts`) and translate the values; keep every `{placeholder}`.
2. Add one line to `LANGS` in `mobile/src/i18n/index.ts`: code, name, short label for the button, direction (`rtl` / `ltr`) and
   date locale.

The menu lists every language in `LANGS`; the top-bar button cycles through them.
