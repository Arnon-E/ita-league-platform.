# רשימת אימות: ערכת החוקים מול תקנוני האיגוד

המערכת לא יכולה לקרוא את קובצי ה-PDF של האיגוד ישירות (הרשת חוסמת), ולכן המספרים נשלפו מסיכום אוטומטי בלבד. עד שאדם בודק כל שורה, ערכת החוקים מסומנת `verified: false` ובממשק מוצג באנר אזהרה בכל תחרות.

איך מאמתים: מסך **חוקים** (`/admin/rules`) → בודקים כל שורה מול המסמך → מתקנים ב-JSON → מסמנים `verified: true` → "פרסום גרסה חדשה". גרסאות ישנות לא משתנות, כך שהגרלות קיימות נשארות ניתנות לשחזור.
