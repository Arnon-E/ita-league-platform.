# אפליקציית מובייל (Expo, אנדרואיד / iPhone / iPad)

לקוח דק מעל `/api/v1` של אפליקציית ה-Web. הקוד עובר typecheck ומתקמפל (bundle) לאנדרואיד ול-iOS; לא נבדק על מכשיר פיזי.

```bash
cd mobile && npm install
# עדכנו extra.apiUrl ב-app.json לכתובת השרת
npx expo start
```

מסכים: כניסה, רשימת תחרויות, משחקי תחרות, הזנת תוצאה מהירה. רישום push והתראות אחרונות כלולים. כולל כניסה, תחרויות, הזנת תוצאה, האזור שלי (העלאת מסמכים, הרשמה, תשלום, התראות).
